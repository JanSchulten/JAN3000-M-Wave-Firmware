M-Vave-OP1 Emulator

Die Custom-Firmware für das M-VAVE FM-1, als WebAssembly im Browser. Dieselben Quellen wie auf dem Gerät: Engines, Sequencer und Bildschirm, nur die Hardware ist simuliert.

Kern lädt … Ton aus Alle gespeicherten Projekte löschen?

Maus: Taste drücken, Regler ziehen oder mit dem Mausrad drehen. Shift-Klick hält eine Taste fest (für Kombinationen wie GLO + PLAY).

Workflows zum Ausprobieren

Z…' weiße Tasten, S D F H … schwarze
Q…O die oberen Tasten
1…6 FX SCL ENV LFO EDIT GLO
7 8 9 0 - = HOME SAVE ARP SEQ PLAY REC
[ ] OCT− OCT+ · ↑ ↓ SELECT · ← → ALGORITHM

Inoffiziell, kein Produkt von M-VAVE. M-Vave-OP1 ist ein Fork von Felucca (Leo Kuroshita, Hügelton Instruments), GPL-3.0; der Browser-Aufbau folgt Felluccas und X0X' Emulator. Projekte, die du auf dem virtuellen Gerät speicherst (mit ihren Szenen), bleiben nur in diesem Browser.
