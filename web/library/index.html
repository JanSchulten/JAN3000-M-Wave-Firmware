BackupSicherung

ImportantThe library lives in this browser's storage. That can be lost (browser data cleared, the page not opened for a long time): keep the ZIP file or the .FM1 files as well. The ZIP file can be added again above, on any device.

WichtigDie Bibliothek liegt im Speicher dieses Browsers. Der kann verloren gehen (Browserdaten gelöscht, Seite lange nicht geöffnet): bewahre die ZIP-Datei oder die .FM1-Dateien zusätzlich auf. Die ZIP-Datei lässt sich auf jedem Gerät oben wieder hinzufügen.

JAN3000 @JAN@, based on Felucca @VERSION@ by Leo Kuroshita (Hügelton Instruments), GPL-3.0-only. Source: github.com/JanSchulten/JAN3000-M-Wave-Firmware. What you hear is computed by the FM-1's firmware here in the browser: the mix as the device sends it over USB audio (44.1 kHz). Chance falls the same way on every render. Quelltext: github.com/JanSchulten/JAN3000-M-Wave-Firmware. Was du hörst, rechnet die Firmware des FM-1 hier im Browser: der Mix, wie ihn das Gerät über USB-Audio ausgibt (44,1 kHz). Zufall fällt bei jedem Rendern gleich.
